Напиши программу из четырех кусочков:

1. `while` с выражением продолжения: выведи степени двойки (1, 2, 4, 8...), пока они меньше 100.
2. `for` с индексом: найди индекс максимального элемента массива.
3. `for` по двум массивам: посчитай скалярное произведение (сумма произведений пар элементов).
4. Помеченный `break`: пройди по "таблице" из массива массивов и найди позицию первого числа, кратного 7.
