Доведи индексатор до полноценной утилиты:

1. Реализуй `indexer <dir>` с рекурсивным обходом через `std.Io.Dir.walk`.
2. Пропускай `.git`, `.zig-cache`, `zig-out` (и другие каталоги по желанию).
3. Считай файлы и байты по расширениям, сортируй по убыванию размера.
4. Добавь флаг `--json`: вывод в JSON через `std.json.fmt`.
5. Добавь флаг `--top N`: только первые N расширений.
6. Обрабатывай ошибки отдельных файлов, не падая целиком: логируй и продолжай.
7. Покрой тестами `extension`, `shouldSkip`, сортировку и `scan` на временном каталоге.
8. Собери `ReleaseFast` и проверь на реальном проекте.
