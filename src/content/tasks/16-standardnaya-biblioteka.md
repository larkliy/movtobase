Напиши анализатор текста:

1. Прочитай файл через `std.Io.Dir.cwd().readFileAlloc(init.io, path, gpa, .limited(1 << 20))`.
2. Посчитай частоту слов через `std.StringHashMap(usize)`. Слова - последовательности букв/цифр; остальное - разделители.
3. Ключи копируй через `dupe`, освобождай в `deinit`.
4. Отсортируй топ-10 слов через `std.mem.sort` по убыванию частоты.
5. Выведи результат в JSON через `std.json.fmt` (можно вручную собрать структуру).
6. Добавь измерение времени через `std.Io.Clock.Timestamp` и вывод в миллисекундах.
7. Запусти на файле с кириллицей и объясни, почему `std.mem` работает с байтами, а не с Unicode-символами.
